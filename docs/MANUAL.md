# Partner.execute(me); · 使用手册

> 名字出处：程序名致敬 Mili 的歌曲《world.execute(me);》（专辑《Miracle Milk》，2016）。

## 1. 托盘菜单

右键任务栏托盘图标：

| 菜单项 | 说明 |
| --- | --- |
| 打开 Partner.execute(me);（聊天）… | 主界面：聊天与角色是同一窗口的两个视图 |
| 电脑操作（看屏幕/点按钮）… | CUA 面板：让她看屏幕、帮你点按钮 |
| 角色 / 形象 / 语音… | 形象管理（VRM / 立绘）、语音音色 |
| 切换角色 | 人格与形象一起切 |
| 角色设置… | 完整设置页 |
| 开始/结束学习 | 陪学模式开关 |
| 隐藏/显示桌面层 | 一键收起 / 呼出桌宠（可设快捷键） |
| 游戏模式（角色躲到角落） | 手动开关游戏模式 |
| 开机自动启动 | 开机静默启动 |
| 打开配置目录 | 打开 `%APPDATA%\ryza-assistant-app\` |
| 退出 | 退出（自动保存） |

左键点托盘图标 = 直接打开聊天界面。

## 2. 桌宠交互

- **左键**：摸一摸（有反馈）
- **拖拽**：拎起来移动，松手放下；甩动会有抛掷惯性
- **右键（角色身上）**：快捷菜单
- **自主行为**：低频待机小动作、偶尔走动、坐在 AuraDesk 卡片上休息；全屏游戏/视频时自动让位

## 3. 游戏模式

进入方式：托盘勾选 / 她自己发现你在玩（自动检测）/ 帮你启动游戏时自动进入 / 设置页按钮。

**「待在哪」设置（角色 → 设置 → 游戏）**：

- 四个角落任选，进入后缩到角落、退出滑回原位（平滑移动，不再瞬移）
- **不固定（保持原位）**：进出游戏模式**只缩放、不搬家**——适合角色常驻副屏的布局
- 进入后大小：滑杆 0.4×–1.2×
- 游戏中静音：默认开（不说话；想让她说话就关掉）

**自动进退**：

- 已认名单：FF14、星穹铁道、原神、绝区零；窗口化游戏可在配置 `global.companion.gameAutoProcesses` 里加进程名
- 切屏回消息/刷视频，**3 分钟内不算离开**（`gameAutoLeaveMin` 可调 1–60 分钟）：计时、位置、弹幕都保持
- 真退出后 40 分钟内回到同一款游戏，**接着上一场算时间**，不重播开场白
- 玩了什么、玩多久，自动写进她的记忆（`gamesess`），她会记得陪你打过的游戏

**弹幕层**：游戏模式里她的话改成横向飘过的弹幕 + 角落弹幕框，不挡游戏。

## 4. 学习模式

- 托盘「开始学习」或她说开始；结束自动写学习账本
- 监督判定四分类（读屏判定，可关）：
  - **study** 在学习 → 偶尔夸
  - **fun** 在玩 → 生气阶梯（提醒 → 严肃 → 骂）
  - **away** 黑屏/锁屏 = 人不在 → 不涨怨气、不记账、自动静默收场
  - **unsure** 亮屏但看不出 → 限频温柔问（最多 2 次、间隔 15 分钟以上）
- 自动陪学与手动陪学同一套规则，抽查间隔约 20–30 分钟（手动 9–21 分钟）
- 账本在 `workspace/study/ledger.json`，设置页可看

## 5. 语音

- **语音识别（ASR）**：本地 faster-whisper；模型 small/medium 在设置里选，中文识别带繁转简
- **语音合成（TTS）**：本地引擎或云端音色，音色可选
- 按住气泡麦克风说话即可；录音只在本地处理

## 6. 聊天与记忆

- 主界面即聊天窗口；支持流式输出、工具调用（她会真的去开程序/搜网页）
- **长期记忆**：对话里她认为重要的事会记进账本；她记错的你可以在设置 → 记忆里删掉
- **看屏幕**（可关）：她定期看一眼前台窗口，聊天时知道你在干嘛
- 语言守卫：角色设置里可锁回复语言（zh/en/ja）

## 7. 配置速查（`%APPDATA%\ryza-assistant-app\config.json`）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `global.companion.gameModeCorner` | `bottom-right` | 游戏模式待哪：`none` = 不固定保持原位 |
| `global.companion.gameModeScale` | `0.7` | 游戏模式缩放 |
| `global.companion.gameModeMute` | `true` | 游戏中静音 |
| `global.companion.gameAutoOn` | `true` | 自动检测进游戏模式 |
| `global.companion.gameAutoLeaveMin` | `3` | 切屏宽限分钟（1–60） |
| `global.companion.gameAutoProcesses` | 内置名单 | 追加的游戏进程名数组 |
| `global.petScale` | `1` | 平时大小 |
| `global.petPos` | 自动 | 桌宠位置（拖动自动落盘） |
| `global.autoLaunch` | `false` | 开机自启 |
| `provider.*` | — | LLM 接口（baseURL/apiKey/model） |

> 改配置请先退出程序再改，改完启动。程序运行时会覆盖手改的内容。

## 8. 常见问题

- **小人不见了**：托盘「显示桌面层」；或检查是否处于全屏让位
- **说话没反应**：设置 → 语音 里确认本地 ASR 已启用、模型已下载
- **游戏模式没自动进**：游戏是否窗口化且不在名单 → `gameAutoProcesses` 加进程名
- **换电脑迁移**：整个 `%APPDATA%\ryza-assistant-app\` 拷过去即可（记忆/配置/模型全在里面）
